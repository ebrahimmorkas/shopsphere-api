# ShopSphere

A production-grade e-commerce REST API built with **ASP.NET Core 10** following **Clean Architecture** principles.

> 🚧 Work in progress — see the roadmap below.

## Roadmap

- [ ] Domain model (products, categories, orders)
- [ ] Persistence with EF Core 10 + PostgreSQL
- [ ] Product catalog (CQRS, validation, pagination)
- [ ] Authentication & authorization (JWT + refresh tokens)
- [ ] Order management
- [ ] Caching, observability, rate limiting
- [ ] Integration tests with Testcontainers
- [ ] Docker & CI/CD
